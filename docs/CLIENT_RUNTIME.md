# Падение Java при запуске клиента

В отчёте `mod/run/hs_err_pid17428.log` от 2026-10-04 Temurin 17.0.15+6
завершился с `EXCEPTION_ACCESS_VIOLATION` в `jvm.dll`. Текущий поток:
`C2 CompilerThread2`; текущая задача: `FluidState.tick`. Это падение нативного
JIT-компилятора Java, а не Java-исключение тигля. Предупреждение книги рецептов
`Unknown recipe category: thaumcraft:arcane_wand` не объясняет этот сбой.

На Windows Gradle-запуск `runClient` теперь по умолчанию передаёт клиентской JVM
`-XX:TieredStopAtLevel=1`: работает JIT C1, компилятор C2 не запускается.
Команда остаётся прежней: `./gradlew.bat runClient` из каталога `mod`.
Этот обход может снизить производительность клиента. Сборка, сервер,
GameTest и распространяемый JAR этим параметром не изменяются.

Параметр `-PsafeClientJit=false` возвращает обычную компиляцию для проверки
на другой Java 17. `-PsafeClientJit=true` включает обход явно на любой ОС.
Обход устраняет именно путь к упавшему C2; отсутствие других проблем
проверяется запуском клиента и входом в мир.
