# Русская локализация modern-порта

В Minecraft 1.20.1 используются JSON из
`mod/src/modern/resources/assets/thaumcraft/lang/`. Старые `.lang` из
`mod/src/main/resources` и `mod/thaumcraft_src` служат источниками для сверки,
но не входят в modern resource set.

## Сверка 2026-10-05

- До этого захода уже было 899 ключей EN/RU, включая русский текст оригинального
  TC4. Перевод не потерян; переимпортировать его целиком не требуется.
- Названия «Перегонный куб», «Банка», «Сбалансированный кристалл»,
  «Записки исследований» и «Стол исследований» приведены к сохранённому
  `mod/thaumcraft_src/assets/thaumcraft/lang/ru_RU.lang`.
- Salis Mundus показан как «Соль тауматурга»: это русское название из страницы
  оригинала `tc.research_page.CRUCIBLE.5`. Латинское название в исходных
  страницах книги сохранено. Названия аспектов Aer, Aqua и т. п. остаются
  оригинальными; перевод их значения уже есть в описаниях аспектов.
- Подсказка заблокированного исследования теперь говорит, что оно ещё не
  изучено, вместо устаревшего утверждения о недоступности в порте.
- В старой вводной странице исправлен рецепт таумометра: золотые слитки,
  как в действующем JSON-рецепте. В ёмкости жезла используется «Вис».
- В EN/RU добавлена пропущенная страница улучшения Vampire Bats, на которую
  ссылается существующее дерево. Это восстановление текста, не реализация
  набалдашника. Экспортёр теперь забирает все ключи страниц из дерева,
  включая `focus.upgrade.*`, а не только `tc.research_*`.
- Текстовый просмотр книги скрывает содержимое `<IMG>...</IMG>` целиком:
  путь к текстуре и координаты больше не выводятся как текст. Иллюстрации
  пока не рисуются — это часть дальнейшей переработки книги.

## Проверка

Из корня репозитория в PowerShell 7:

```powershell
.\scripts\verify-modern-localization.ps1
```

Проверяются уникальность/непустые значения JSON, равенство наборов EN/RU,
форматные параметры, ссылки всех названий/описаний/страниц/категорий дерева
и буквальные ключи modern UI. Это проверка покрытия, а не качества каждой
фразы оригинального перевода. Опечатки всех старых страниц ещё не вычитаны.

Сборка: из `mod` выполнить `.\gradlew.bat build`. Проверка русских переносов,
масштаба GUI и читаемости в игре оставлена для следующего запуска пользователем.

Результат этого захода: build прошла; проверены 900 EN/RU ключей и 728
ссылок интерфейса/книги. Наличие обновлённых 900 русских ключей подтверждено
в собранном JAR. Игровой клиент не запускался.
