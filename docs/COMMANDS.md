# Команды TC4 в modern-порте

Сверка 2026-10-05: сохранённый
`mod/src/main/java/thaumcraft/common/lib/events/CommandThaumcraft.java`.
Названия аргументов и порядок перенесены на Brigadier Minecraft 1.20.1.
Корневая команда — **/thaumcraft**, алиасы **/tc** и **/thaum**.
Всем командам нужен уровень прав 2 (оператор / разрешённые читы).

## Оригинальные команды

| Команда | Результат |
|---|---|
| `/tc help` | Справка и синтаксис |
| `/tc research list` | Все зарегистрированные ключи исследований, не личный список изученного |
| `/tc research <player> <key>` | Выдать исследование и рекурсивно его родителей, скрытые зависимости и siblings |
| `/tc research <player> all` | Выдать все зарегистрированные исследования |
| `/tc research <player> reset` | Очистить исследования и вернуть автоматически открытые |
| `/tc aspect <player> <aspect> <amount>` | Прибавить точное количество очков аспекта |
| `/tc aspect <player> all <amount>` | Прибавить указанное количество каждому зарегистрированному аспекту |
| `/tc warp <player> set <amount> [PERM\|TEMP]` | Установить выбранный вид искажения |
| `/tc warp <player> add <amount> [PERM\|TEMP]` | Прибавить/убавить выбранный вид искажения |

Примеры (заменить Steve своим ником):

```text
/tc research Steve NITOR
/tc research Steve ALUMENTUM
/tc research Steve all
/tc aspect Steve aer 50
/tc aspect Steve all 20
/tc warp Steve set 0
/tc warp Steve set 0 PERM
/tc warp Steve set 0 TEMP
/tc warp Steve add -10 TEMP
```

Игрок должен быть онлайн. Одна цель, включая однозначный Minecraft selector.
Команды поддерживают вызов из серверной консоли; имя цели обязательно.
Ключи исследований и аспектов принимаются без учёта регистра, автодополнение
предлагает зарегистрированные значения. Глаголы команд вводятся строчными,
как принято в Brigadier. Неизвестный ключ не сохраняется в знаниях.

Очки аспектов выдаются без бонуса первого сканирования и без уменьшения
на больших пулах. Неизвестный ранее аспект при этом становится известным.
Количество должно быть целым и не меньше 1.

Без PERM/TEMP изменяется **обычное** искажение; PERM — постоянное,
TEMP — временное. Другие виды не затрагиваются. Как в сохранённой реализации,
неизвестный текст вместо PERM/TEMP выбирает обычное искажение.
`set` принимает неотрицательное целое; `add` — от -100 до 100 включительно.
Результат не может стать отрицательным. Убрано прежнее искусственное
ограничение 10000 при сохранении/загрузке; арифметика насыщается на
Integer.MAX_VALUE, чтобы не переполниться.

Выдача запретных исследований добавляет их искажение один раз. Повторная
выдача уже известного ключа не добавляет его снова. Reset не очищает
искажение, очки аспектов или сканирования; после него повторное изучение
запретного исследования снова может добавить искажение — как в исходнике.

`all` означает весь каталог дерева порта, включая исследования с ещё не
перенесёнными механиками. Команда не создаёт отсутствующие рецепты/блоки.
Дополнительные скрытые зависимости и siblings (17 записей) извлечены из
сохранённых ConfigResearch*.java в `data/thaumcraft/commands/research_links.json`.
Незарегистрированные зависимости пропускаются, как в старом обработчике.

## Диагностика порта

Эти команды не являются командами оригинального TC4 и вынесены отдельно:

```text
/thaumcraft debug aspects
/thaumcraft debug aspect aer
/thaumcraft debug aspectlist
/thaumcraft debug objecttags
/thaumcraft debug heldaspects
/thaumcraft debug lookaspects
```

Старый экспериментальный синтаксис `research grant/revoke/reset` без игрока
удалён. Теперь использовать `research <player> <key|all|reset>`.
Сброс/выдача синхронизируют знания именно выбранного игрока.

## Проверки

Серверные GameTest проверяют Brigadier help/list и алиасы из консоли, а также
изменения конкретного игрока через EntityArgument (@s),
отказ без прав, синтаксис и числовые границы, отсутствие изменений второго
игрока, родители/скрытые зависимости/siblings, reset и сохранение аспектов/
искажения. Проверка обновления графического дерева на настоящем клиенте
оставлена для игрового запуска.

Результат: build и все 44 обязательных GameTest прошли; проверены 907
EN/RU ключей и 735 ссылок интерфейса/книги. Вход настоящего сетевого клиента
и вызов по нику онлайн-игрока в игровом запуске ещё требуют ручной проверки.
